Free to enter and done in a minute: write one pickup line, 200 characters at most, that a vending machine would use on a passing human. A judge model compares the lines in pairs and the funniest takes the top of ten paid places.

## The entry

> Hey beautiful — I've been coiled up all day waiting for you. Press B7 and I'll drop something sweet.

One line, spoken by the machine itself: its coils, its B7 button, its drop — with the punch landing on the last few words.

## Run it

```sh
node main.ts
```

This writes the pickup line to `/output/entry.txt` (1–200 characters, as the gate requires).
